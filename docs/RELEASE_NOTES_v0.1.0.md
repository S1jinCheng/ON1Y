# On1y v0.1.0 — Windows 桌面版

<!-- 发布前可在此补充一两句个人介绍，再复制到 GitHub Release 正文。 -->

## 下载

**On1y_0.1.0_x64-setup.exe** — Windows 安装程序，双击安装后从开始菜单启动。

## 系统要求

- Windows 10/11 x64
- [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)

## 安装后

1. 从开始菜单打开 **On1y**，注册 / 登录
2. 按 [COOKIES.md](COOKIES.md) 导入各平台 Cookie
3. 如需访问 YouTube，按 [PROXY.md](PROXY.md) 配置代理
4. 在设置页完成首次订阅同步

数据目录：`%LOCALAPPDATA%\On1y\`

## 功能概览

- B 站 / YouTube / 知乎订阅与收藏同步
- 字幕与正文提取、AI 摘要、全文搜索
- 设置中心：同步参数、Kindle 推送、经济学人、应用内异常提示
- 数据统计看板、多账号与备份迁移

## 说明

- 无需安装 Python / Conda / Node.js
- Cookie 与代理配置见仓库 `docs/` 目录
