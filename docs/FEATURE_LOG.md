## 产品约定

- **今日（Today）**：在「全部」中用日历按发布日期筛选；未读仍走「未读」专栏。
- **已读判定**：满足以下**任意一条**即标为已读——  
  - 点开原文链接（跳转站外）  
  - 点开展开阅读（阅读器 / 正文面板）
