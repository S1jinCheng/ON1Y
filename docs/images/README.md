# README 素材

将以下文件放入本目录，README 中的图片/视频链接即可生效。

| 文件 | 建议尺寸 | 用途 |
|------|----------|------|
| `banner.png` | 1280×320 或 1200×400 | 顶部标题图（可用 [Canva](https://www.canva.com/) 制作） |
| `workbench.png` | 1920×1080 | 工作台截图 |
| `settings.png` | 1920×1080 | 设置页截图（可选） |
| `demo-poster.png` | 1280×720 | 演示视频封面（可选） |
| `demo.mp4` | 1080p，1～3 分钟 | 演示视频（见下方说明） |

## 演示视频怎么放

On1y 是本地应用，没有公网在线 Demo。推荐：

1. **GitHub README 内嵌**：把 `demo.mp4` 拖到 GitHub Issue 评论框上传，复制生成的 `user-images.githubusercontent.com` 或 `github.com/user-attachments` 链接，替换 `README.md` 里的视频地址。
2. **外链**：录好后上传 B 站 / YouTube，在 README 里放链接或封面图跳转。
3. **随 Release 附件**：在 GitHub Release 页上传 mp4，README 里链到 Release 资源。

录制建议：安装正式版 → 登录 → 导入 Cookie → 同步几条内容 → 展示搜索与摘要，约 90 秒。
