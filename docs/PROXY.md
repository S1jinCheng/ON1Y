# 网络代理

## 原则

你在浏览器里**没有代理就上不去**的网站，On1y 访问时**同样需要代理**。

常见需要代理的场景：**YouTube**、**GitHub**（如经济学人周刊同步）、**X** 等。  
**哔哩哔哩**、**知乎**等国内平台一般不需要，配好 Cookie 即可。

---

## 配置规则

在 **设置 → 通用 → 网络 / YouTube 代理** 中配置：


| 模式         | 规则                                                          |
| ---------- | ----------------------------------------------------------- |
| **自动**（默认） | 依次尝试：`.env` 中的 `ON1Y_YTDLP_PROXY` → Windows 系统代理 → 本机常见本地端口 |
| **手动**     | 使用设置页填写的代理地址；未填写时回退 `.env` 中的 `ON1Y_YTDLP_PROXY`            |
| **关闭**     | 不使用任何代理，适用于可直连外网的网络                                         |


- 地址格式：`http://主机:端口`；省略协议时自动补 `http://`
- 设置按用户保存在本机，改完后立即生效，无需重启
- 可用 **测试代理** 检查当前地址能否连通 YouTube

---

## 说明

- 代理仅用于 On1y 发起的出站请求，不影响你在浏览器里单独上网
- 若同步仍失败，先确认浏览器在相同网络下能否打开目标站，再检查 Cookie 是否有效（见 [COOKIES.md](COOKIES.md)）
- 高级用户可在 `.env` 设置 `ON1Y_YTDLP_PROXY` 作为自动模式的候选之一
