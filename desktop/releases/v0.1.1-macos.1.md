# On1y v0.1.1-macos.1 · Apple Silicon 预览版

首个 Mac 桌面预览版，应用内版本号为 0.1.1。本次只提供 Mac 安装包，Windows 正式版保持不变。

## 下载与安装

- 下载 `On1y_0.1.1_aarch64.dmg`，打开后将 On1y 拖入 Applications。
- 支持 Apple Silicon（M 系列芯片），要求 macOS 14 或更新版本。已在 macOS 15.7.3 验证；本次不提供 Intel 版本。
- 无需安装 Python、Node.js 或 Rust。安装包较大，因为包含本地后端、OCR 依赖和浏览器组件。
- 当前仅使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证。Gatekeeper 可能阻止首次打开，请只在确认下载来源后使用系统设置的隐私与安全选项授权，不要关闭系统整体安全保护。
- 同时提供 SHA-256 校验文件。

## 本次内容

- 原生 Mac 窗口、菜单栏图标、开机启动和 PDF 应用选择。
- 修复首次启动、登录 500 和 Mac 文献库默认目录问题；运行数据保存在用户目录，不写入应用包。
- 支持 Windows `.on1y.zip` 备份导入，修复特殊 Unicode 字符导致的 JSON 解析失败。
- 修复跳过导入仍覆盖关联备注、覆盖导入残留旧摘要和旧关联的问题，导入处理不再占用服务事件循环。
- 增加可选的个人 Win / Mac 同步功能。默认关闭；需自行配置可信同步中转服务，不会自动上传数据。

## 迁移说明

在 Windows 导出账户数据后，在 Mac 创建或登录本地账户，再从设置中的账户数据页面导入。迁移的是知识库和可选订阅配置，不会把 Windows 登录密码同步到 Mac。

如需迁移 Cookie，请在导出时单独勾选，并妥善保管备份，不要上传到公开仓库。该发布包不包含任何用户数据库、Cookie 或私密配置。

覆盖导入会以备份中的条目内容为准；保留 Mac 上已有条目时请选择跳过。建议迁移前分别备份两台设备的数据。

## 验证与限制

后端回归、前端测试、原生桌面测试和打包后的登录、导入导出、冲突处理测试均已验证，详细记录见 `desktop/MACOS-VALIDATION.md`。

本版为预览版。Intel、macOS 14 实机、Apple 公证分发及所有第三方平台的真实账号同步尚未完成验证。OCR 模型可能在首次使用时下载。
